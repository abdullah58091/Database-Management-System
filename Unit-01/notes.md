# Unit 1 Theory

## Introduction to Database

A database is an organized collection of related data.

## DBMS

DBMS (Database Management System) is software used to create, manage, and retrieve data from databases.

## Evolution of Database Systems

Database systems evolved from traditional file systems to DBMS for efficient data management.

## Relational Model

A relational model stores data in tables consisting of rows and columns.

## Hierarchical Model

A hierarchical model stores data in a tree-like parent-child structure.

## Network Model

A network model allows multiple relationships between records.

## Importance of DBMS

DBMS provides secure, organized, and efficient data management.
